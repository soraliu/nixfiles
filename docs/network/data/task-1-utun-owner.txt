## 结论
utun7 = **Nebula overlay VPN**（root 用户 sudo 启动的 nebula 进程持有）：
- mtu 1300 与 Nebula 默认 MTU 一致
- 10.10.10.200 = 本机 Nebula overlay IP；10.10.10/24 = Nebula 虚拟网段
- 用途：k9s/Codex 经 overlay 访问 10.10.10.11:6443（某 Kubernetes 集群 API）
- 与 jumbo MTU 研究的关联：utun7 不承载内网 192.168.31.0/24 流量（默认路由与内网均走 en11），不影响内网 path-MTU；但其 mtu 1300 表明 overlay 内 k8s 流量已被压缩在 1300 以内
