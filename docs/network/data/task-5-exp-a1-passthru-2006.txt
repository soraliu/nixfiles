# A1·透传证据链 (NAS eth0=2034 → Mac en11=1500) — 2026-10-12 12:33:10
# 方法: NAS 发 DF 2006B echo request ×100 → Mac RX 计数(Ipkts) 差分 ≈100(±5) = 帧到达 Mac = 哑交换机透传成功
# 预期: NAS 侧 100% 超时 (Mac TX MTU 1500 无法回程 2034 reply) — 不算失败, 判定只看 Mac RX

## BEFORE

$ netstat -I en11
Name       Mtu   Network       Address            Ipkts Ierrs    Opkts Oerrs  Coll
en11       1500  <Link#23>   90:e3:ba:03:40:d1 38234418     0 81953793     0     0
en11       1500  m3-5.local  fe80:17::1c8f:155 38234418     - 81953793     -     -
en11       1500  192.168.31    192.168.31.120  38234418     - 81953793     -     -

$ netstat -s -p icmp | grep -iE 'messages generated|too long|frag|histogram|echo'
	Output histogram:
		echo reply: 3
	0 multicast echo requests ignored
	Input histogram:
		echo reply: 1634
		echo: 3

$ netstat -s -p ip | grep -iE 'received|delivered'
	16066686 total packets received
		0 fragment received
		3 packets received for unknown multicast group

# 生效值: IPKTS_BEFORE=38234418  ICMP_echo_reply=echo

## NAS 侧发送 100 包 (iputils ping -M do -s 2006 -c 100 -i 0.05 192.168.31.120)

$ ssh root@192.168.31.3 "ping -M do -s 2006 -c 100 -i 0.05 192.168.31.120"
PING 192.168.31.120 (192.168.31.120) 2006(2034) bytes of data.
